COMO MUDAR O TEMA NA TELA

Exemplo: trocar a lista de tarefas por uma lista de produtos.
Altere somente os textos indicados abaixo.


1. ARQUIVO: public/index.html

Este arquivo contém os campos e o texto da aba do navegador.

Procure:
<title>Lista de tarefas</title>

Troque por:
<title>Lista de produtos</title>


Procure:
<input id="titulo" placeholder="Título" maxlength="200" required>

Troque por:
<input id="titulo" placeholder="Nome do produto" maxlength="200" required>


Procure:
<input id="descricao" placeholder="Descrição">

Troque por:
<input id="descricao" placeholder="Descrição do produto">

O placeholder é o texto que aparece dentro do campo vazio.
Mantenha id="titulo" e id="descricao" iguais.


2. ARQUIVO: public/js/acesso.js

Este arquivo coloca o nome do usuário na tela.

Procure:
document.getElementById('boasVindas').textContent = 'Lista de ' + usuario.nome

Troque por:
document.getElementById('boasVindas').textContent = 'Produtos de ' + usuario.nome

Exemplo do resultado na tela:
Produtos de Cleyton


3. ARQUIVO: public/js/tarefas.js

Este arquivo contém as mensagens da lista.
Use Ctrl + H no VS Code para substituir os textos.

Procure:
Nenhuma tarefa.

Troque por:
Nenhum produto.


Procure:
Excluir esta tarefa?

Troque por:
Excluir este produto?

Mantenha as aspas e o restante do código como estão.


PARA USAR OUTRO TEMA

No lugar de produto/produtos, escreva o tema da prova.
Exemplos: livro/livros, serviço/serviços ou chamado/chamados.

Não renomeie arquivos, IDs, variáveis ou rotas para mudar apenas
os textos da tela.

Depois de salvar os arquivos com Ctrl + S, atualize a página.
